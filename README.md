# mlx website

The static website for [ocaml-mlx.github.io](https://ocaml-mlx.github.io).

Run `npm start` to serve it locally at `http://localhost:4327`. Run `npm run check` to check JavaScript and the local TypeScript server syntax. Node.js 22.18 or newer is required for the local server.

The source is on `main` in `index.html`, `style.css`, `app.js`, and `assets/`. GitHub Pages publishes the `gh-pages` branch from the repository root. The site uses static HTML, CSS, and JavaScript; publishing needs no compile phase.
