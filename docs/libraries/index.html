Libraries

Choose a UI library for the browser, server, terminal, or desktop. mlx supplies syntax, not a renderer.

React components

Use Melange to compile OCaml to JavaScript and reason-react for browser components. mlx provides the JSX-shaped source; the component library defines the resulting behavior. Melange template ↗

Reativa

Reativa builds web interfaces in OCaml or Reason with signals. Views update real DOM nodes without a virtual DOM. It supports Melange and js_of_ocaml, with a Reativa.View.Mlx adapter and reativa.mlx_ppx for mlx source.

Server HTML

With Dream and html_of_jsx, a server route can return HTML from JSX-shaped OCaml source. The rendering path belongs to those libraries. Dream integration example ↗

Yuka

Yuka is an experimental OCaml web framework. It renders JSX pages on the server and streams slow sections as they become ready. Melange compiles interactive islands to JavaScript; pages without islands load no JavaScript.

Typed HTML

A TyXML-facing integration keeps typed HTML construction. Check the PPX chain, attributes, and children in your own project before adopting the syntax.

Terminal interfaces with Mosaic

Mosaic offers terminal widgets, layout, and an Elm-style model/update/view loop. Its Mosaic_mlx module exposes element helpers that accept mlx children. This is a view excerpt; a complete application also supplies a model, update function, and run loop.

Mosaic view excerpt · .mlx
open Mosaic_mlx

let view count =
  <box flex_direction=Column border=true padding=(padding 1)>
    <text>("Count: " ^ string_of_int count)</text>
    <text>"Press q to quit"</text>
  </box>

Desktop applications with mlui

mlui is a declarative OCaml desktop framework with flexbox layout, animations, and Elm-style state updates. Its counter example creates a window with Mlui.Window.make and runs the view through its SDL backend. The current examples use the OCaml API; mlx authoring would need adapter functions that accept mlx children.
