Editor support

Use the mlx reader, formatter, and grammar support where your editor needs them.

Companion packages

Install ocamlmerlin-mlx and ocamlformat-mlx alongside mlx, then add the Dune dialect. The dialect declares the reader and format command.

$opam install mlx ocamlformat-mlx ocamlmerlin-mlx

Available editors

VS Code, Cursor, Windsurf, Antigravity, Zed, Neovim are the editors listed for this prototype's support paths. The exact setup depends on the editor and installed OCaml tooling.

  • OCaml Platform extension for VS Code-compatible editors.
  • Neovim integration for Neovim.
  • Tree-sitter grammar for syntax highlighting.

Another editor?

Missing your editor? Open an issue to help track support.
