Installation

Install the syntax package, register the .mlx dialect with Dune, and keep your editor and formatter in step.

Prerequisites

This guide uses opam and Dune. Before installing mlx, you need:

  • An active opam switch. Run these commands in the environment for the project you want to change.
  • OCaml 4.14 or newer. This is the minimum compiler version declared by the mlx package. Use companion editor and formatter versions compatible with your switch.
  • Dune 3.16 or newer. The dialect below uses merlin_reader, available from Dune 3.16. Your dune-project must also declare (lang dune 3.16) or a newer language version supported by your installed Dune.
  • A Dune project. Work from the directory containing dune-project. If you are starting from scratch, the standalone example includes a complete project.

Check your active switch and tool versions:

Check your environment · shell
opam switch show
ocamlc -version
dune --version

Install mlx

Start with the syntax package. Add its companion packages for formatting and editor support.

$opam install mlx ocamlformat-mlx ocamlmerlin-mlx

You can also install only mlx first with opam install mlx.

Add the Dune dialect

Place this dialect in dune-project. It connects the file extension, Merlin reader, formatter, and preprocessing step. If you installed only mlx, leave out merlin_reader and format until you install their companion packages.

dune-project
(dialect
 (name mlx)
 (implementation
  (extension mlx)
  (merlin_reader mlx)
  (format
   (run ocamlformat-mlx %{input-file}))
  (preprocess
   (run mlx-pp %{input-file}))))

Check a module

Add Greeting.mlx to a directory covered by your project's library or executable stanza, then run dune build:

Greeting.mlx
let greeting ~name () =
  <div>
    <h1>("Hello, " ^ name ^ "!")</h1>
    <p>"Welcome to mlx."</p>
  </div>

In a fresh project with only the mlx toolchain and no element functions or JSX runtime PPX, you should see:

Expected compiler error
Error: Unbound value div

This means the JSX syntax was parsed and the compiler reached the call to div. mlx does not define that function. A UI library's PPX can transform the marked calls into the library's element operations, or you can supply ordinary OCaml functions yourself.

Choose a JSX library

Follow a library's guide to add its runtime and PPX to your Dune stanza:

  • html_of_jsx: Getting started for HTML rendering.
  • reason-react: Installation for React with Melange. Keep the mlx dialect when using .mlx files.

Follow that library's conventions for children and attributes too. The syntax-only example above is not a complete application for every runtime. You can also run the self-contained compiler example without a framework.
