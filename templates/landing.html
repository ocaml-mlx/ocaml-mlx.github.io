for practical OCaml teams

JSX in OCaml, without breaking everything around it.

mlx adds JSX syntax with a minimal parser and tooling delta, so your project keeps the same ecosystem shape while authoring UI in a cleaner form.

Start with setup Read syntax reference
  • Works with Melange and js_of_ocaml workflows
  • Stays close to normal dune, merlin, and formatter paths
  • Designed as syntax sugar, not a parallel runtime universe

Install

opam install mlx Optional: ocamlmerlin-mlx, ocamlformat-mlx
