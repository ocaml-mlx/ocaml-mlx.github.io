## Primary starting points

- [`andreypopp/melange-mlx-template`](https://github.com/andreypopp/melange-mlx-template) - a purpose-built template for Melange projects using mlx.
- [`melange-community/create-melange-app`](https://github.com/melange-community/create-melange-app) - the broader Melange scaffold that mlx can slot into.
- [`pdelacroix/vite-plugin-melange`](https://github.com/pdelacroix/vite-plugin-melange) - a Vite plugin for Melange workflows.

## Reference integrations

- [`camlworks/dream#330`](https://github.com/camlworks/dream/pull/330) - Dream discussion and example material around mlx integration.
- [`html_of_jsx`](https://github.com/davesnx/html_of_jsx) - HTML-first rendering path that works well with server-side mlx usage.

## How to pick one

- Start with a **template** when you want to ship quickly and prefer known-good wiring.
- Start with a **reference integration** when you already have an existing codebase and only need the dialect and PPX story.
