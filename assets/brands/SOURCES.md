# Brand assets

- `github.svg`: https://cdn.simpleicons.org/github — Simple Icons GitHub mark. Changed only the root fill to `currentColor`.
- `discord.svg`: https://cdn.simpleicons.org/discord — Simple Icons Discord mark. Changed only the root fill to `currentColor`.
- `opam-monochrome.png`: derived from the official opam camel-and-package icon at https://opam.ocaml.org/ext/img/opam.png for the grey header mark. RGB is black; alpha is multiplied by `1 - min(R, G, B) / 255` so white areas become transparent and the camel cutout remains visible. Dimensions remain 357 × 310.
