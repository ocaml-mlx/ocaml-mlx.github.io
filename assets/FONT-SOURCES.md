# Font sources

Geist and Geist Mono are self-hosted. Both use the SIL Open Font License; the license files are `geist-OFL.txt` and `geistmono-OFL.txt`.

The site uses local variable WOFF2 subsets for Geist and Geist Mono. These are the Latin and Latin Extended files returned by the Google Fonts CSS API on 2026-11-24 for `https://fonts.googleapis.com/css2?family=Geist:wght@100..900&family=Geist+Mono:wght@100..900&display=swap` with a modern Chrome user agent:

- `geist-latin.woff2`: https://fonts.gstatic.com/s/geist/v5/gyByhwUxId8gMEwcGFWNOITd.woff2
- `geist-latin-ext.woff2`: https://fonts.gstatic.com/s/geist/v5/gyByhwUxId8gMEwSGFWNOITddY4.woff2
- `geist-mono-latin.woff2`: https://fonts.gstatic.com/s/geistmono/v6/or3nQ6H-1_WfwkMZI_qYFrcdmhHkjko.woff2
- `geist-mono-latin-ext.woff2`: https://fonts.gstatic.com/s/geistmono/v6/or3nQ6H-1_WfwkMZI_qYFrkdmhHkjkotbA.woff2

`geist-fonts.css` retains the source subset ranges. The license files above apply to these subsets.
